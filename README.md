# NEW GENERATION NETWORK (N.G.N.)

Christian ministry mobile application.

## Vision
Raising a righteous generation for Christ.

## Mission
To spread the Gospel of Jesus Christ, inspire lives, strengthen faith, and bring hope to people around the world through impactful Christian content.

## Architecture
- Flutter mobile application
- GitHub source control
- Supabase backend
- Public app access without normal user accounts
- Administrator authentication only

## Build phases
1. Phase 1 — clean Flutter foundation
2. Phase 2 — Supabase backend and administrator system
3. Phase 3 — complete content, offline features, media, and production polish

## Verification
The Phase 3 verification workflow is configured to validate the Flutter app and Bible data on pushes to main.
